# Getting Started

## Fast review

1. Open `SKILL.md`.
2. Paste it into a capable AI assistant.
3. Supply a system description, PRD, model card, procurement document, workflow, or mission concept.
4. Ask for a Rights by Design review.
5. Validate every factual assertion against source evidence.

## Reusable implementation

For ChatGPT, use `chatgpt/INSTRUCTIONS.md` in the Instructions field and upload the Knowledge files listed in `chatgpt/CONFIGURATION.md`.

## Minimum input

Provide the system purpose, affected people, decision or action, data sources, human role, consequences, deployment stage, jurisdiction, and available safeguards.

## Minimum output

A valid review includes an impact tier, sector overlays, five-dimension scorecard, prioritized controls, owners, evidence, blockers, open questions, and a bottom line.
