# Documentation FAQ

## Is Rights by Design a certification?
No. It is a governance and design method.

## Does every system need every sector module?
No. Apply all universal dimensions and every relevant overlay.

## Can an issue be both a rights and safety problem?
Yes. A system can trigger multiple dimensions and overlays.

## What does “deployment blocker” mean?
A deficiency that should prevent deployment or continued operation until resolved.

## Can an implementation modify the output format?
Yes, provided all required fields in `FRAMEWORK_SPEC.md` remain present.
