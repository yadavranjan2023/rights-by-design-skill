# Sector Overview

Sector modules add domain-specific risks and controls after the five universal dimensions are applied.

| Sector | Principal concerns |
|---|---|
| Employment | Job relevance, adverse impact, accommodation, worker surveillance |
| Lending | Fair lending, reason fidelity, alternative data, substantive reconsideration |
| Healthcare | Clinical safety, subgroup performance, override, incident surveillance |
| Government | Legal authority, due process, public accountability, records |
| Telecommunications | Service access, metadata, emergency communications, network resilience |
| Defense | Command authority, bounded autonomy, provenance, contested operations |
| Space | Mission safety, fault management, communications loss, verification |
| Education | Student rights, accessibility, developmental effects, academic opportunity |
| Insurance | Pricing, underwriting, claims, proxy effects, explanation |
| Law enforcement | Liberty, surveillance, evidentiary reliability, selective enforcement |
| Critical infrastructure | Cascading failure, redundancy, manual fallback, recovery |
| Energy | Grid stability, allocation, outage response, safety |
| Transportation | Passenger and public safety, autonomy, accessibility, incident reconstruction |
| Robotics | Physical safety, control boundaries, human proximity |
| Manufacturing | Worker safety, quality, process control, supply chain |
| Biometrics | Identification error, surveillance, consent, demographic performance |
| Smart cities | Public-space monitoring, access, infrastructure, democratic oversight |
