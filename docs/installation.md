# Installation

## ChatGPT

1. Create a custom GPT.
2. Paste `chatgpt/INSTRUCTIONS.md` into Instructions.
3. Upload `SKILL.md`, `FRAMEWORK_SPEC.md`, methodology, glossary, sector modules, and examples as Knowledge.
4. Add the prompts in `chatgpt/CONVERSATION_STARTERS.md`.
5. Enable web access only when current law, policy, standards, or guidance must be verified.
6. Run the evaluation suite before sharing.

## Generic assistant

Paste `SKILL.md` and provide the relevant sector module with the system materials.

## Local repository

Clone the repository, preserve the directory structure, and use the release checklist before tagging a version.
