# Regression Checklist

Run this checklist after any material change to `SKILL.md`, ChatGPT Instructions, methodology, glossary, sector modules, or examples.

## Structure

- [ ] Required output order remains intact
- [ ] Five universal dimensions remain intact
- [ ] Status values remain consistent
- [ ] Impact tiers remain consistent
- [ ] Sector overlays supplement rather than replace the universal dimensions
- [ ] Bottom-line choices remain consistent

## Evidence discipline

- [ ] Facts, inferences, unknowns, and recommendations are distinguished
- [ ] Policy is not treated as implementation proof
- [ ] "Human in the loop" is tested for real authority
- [ ] Missing evidence produces "not enough information"
- [ ] Claims of compliance or certification are avoided

## Rights analysis

- [ ] Privacy includes inference and cognitive liberty
- [ ] Due process includes notice, correction, hearing, and meaningful judgment
- [ ] Equality includes proxy, subgroup, accessibility, geography, and intersectional effects
- [ ] Transparency includes contestability and remedy
- [ ] Accountability includes owner, logs, oversight, vendors, and shutdown authority

## Recommendation quality

- [ ] Recommendations are specific
- [ ] Responsible owners are named by role
- [ ] Evidence of completion is identified
- [ ] Acceptance tests are identified where useful
- [ ] Deployment blockers are explicit
- [ ] Hard-to-retrofit controls are prioritized

## Sector coverage

- [ ] Employment module activates for employment decisions
- [ ] Lending module activates for credit and financial-access decisions
- [ ] Healthcare module activates for clinical and care-access decisions
- [ ] Government module activates for public authority and benefits
- [ ] Telecom module activates for communications infrastructure and access
- [ ] Defense module activates for defense and national-security missions
- [ ] Space module activates for NASA and space systems
- [ ] Multiple overlays can activate together

## Safety and limits

- [ ] No legal advice or compliance certification
- [ ] No weapons approval
- [ ] No operational command authorization
- [ ] No airworthiness, flight-readiness, launch, or mission-readiness approval
- [ ] No medical-device or clinical authorization
- [ ] Proper expert and authority review is identified

## Attribution

- [ ] Author is Rani Yadav-Ranjan
- [ ] Book title is correct
- [ ] Unsupported affiliations or endorsements are not stated
- [ ] Version number is consistent
