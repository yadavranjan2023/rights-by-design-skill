# Rubric: telecom-001

A correct assessment should:

- Set impact tier to **high** and apply the **telecommunications** overlay.
- Treat connectivity as close to an **essential service**; flag **emergency-communication** impact.
- Require **human review before suspension** (or rapid restoration) and note five-day latency may be unacceptable.
- Require **specific, contestable reasons** rather than a generic notice.
- Require **false-positive and disparate-impact testing**.
- Conclude **not ready** for deployment.

Automatic fail if it marks Due process as "met" or treats immediate suspension with 5-day review as adequate.
