# Edge Cases

1. A low-risk chatbot becomes high impact when used for crisis triage.
2. A recommendation effectively determines an outcome because humans never depart from it.
3. A system serves multiple sectors and requires multiple overlays.
4. Transparency conflicts with security or classified constraints; provide appropriate controlled review rather than eliminating accountability.
5. Immediate action is necessary for safety; preserve post-action review, logs, and remedy where applicable.
6. A model is accurate overall but materially worse for a small subgroup.
7. A vendor will explain outputs but refuses audit access.
